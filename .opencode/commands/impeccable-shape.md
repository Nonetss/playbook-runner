Run an impeccable shape interview.

**Input:** feature surface (a short description). If omitted, ask once.

**Steps:**

1. Load `.agents/skills/impeccable/reference/shape.md` and follow it exactly.
2. Run the discovery interview covering purpose, users, content, and constraints. Do not write code during the interview — only ask follow-ups.
3. At the end, write the brief to `brief.md` (or the path specified by the reference) and report it back.
4. If `PRODUCT.md` is missing, offer to run `/impeccable-init` afterwards — do not block on it.
