Playbook Runner es una consola web autoalojada para Ansible: inventario, credenciales SSH, playbooks, scripts y jobs con cron, con la salida de cada ejecución en directo en el navegador.

<Diagram id="arquitectura" />

> [!WARNING]
> Un playbook válido para `ansible-playbook` puede comportarse de otra forma aquí: `hosts` y `become_user` no deciden nada, las variables llegan como texto y `debug` con `var` no se ve. Antes de escribir uno, lee [las reglas del runner](ejecucion/index.mdx).

## Otras fuentes de verdad

Esta documentación explica cómo encajan las piezas. El resto se enlaza desde aquí y no se copia:

- [La web pública](https://nonetss.github.io/playbook-runner/docs/): instalación y uso, en inglés y español (`apps/site`).
- `AGENTS.md` de la raíz del monorepo: reglas y convenciones exhaustivas para trabajar en el código.
- `openspec/specs/`: el comportamiento exigido de cada capacidad.
- `apps/frontend/DESIGN.md`: el sistema de diseño, normativo.
- `PRODUCT.md`: propósito y modelo de operación.

Si dos sitios se contradicen, manda el código.
